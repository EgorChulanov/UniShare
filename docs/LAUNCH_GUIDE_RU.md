# Запуск UniShare в Telegram, ВКонтакте и в браузере

Пошаговая инструкция: от бота в BotFather до работающего приложения на своём домене.

**Понятия:**
- **Mini App:** веб-приложение, которое открывается прямо внутри Telegram или ВКонтакте.
- **VM (виртуальная машина):** арендованный сервер в облаке.
- **Домен:** адрес сайта вида `unishare.ru`. Telegram и VK открывают Mini App только по HTTPS, поэтому нужен домен с сертификатом. Сертификат получается автоматически.

---

## 1. Выбор хостинга и базы данных

**Рекомендация:** держать базу и сервер **в России**, сначала **Yandex Cloud** (одна VM), а при росте перейти на **Managed PostgreSQL + Object Storage** в том же облаке.

Почему уйти с Supabase:
- **Закон.** По 152-ФЗ (ст. 18, ч. 5) персональные данные граждан РФ нужно хранить в базах на территории России. Supabase размещается за рубежом.
- **Доступность.** Из России доступ к зарубежным облакам нестабилен. Подтверждённой блокировки Supabase Роскомнадзором я не нашёл. Но в 2026 году Supabase блокировали в Индии ([TechCrunch](https://techcrunch.com/2026/02/27/india-disrupts-access-to-popular-developer-platform-supabase-with-blocking-order/)), то есть риск реальный.
- **Нет привязки к поставщику.** Новый сервер работает на обычном PostgreSQL. Переехать к любому провайдеру можно за час: `pg_dump` → `psql`.

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| **Yandex Cloud** (рекомендую) | Крупный российский провайдер, Managed PostgreSQL, S3-хранилище, оплата в рублях, 152-ФЗ | Интерфейс сложнее, чем у VPS |
| Timeweb Cloud / Selectel | Дешёвые VPS, простая панель | Меньше управляемых сервисов |
| VK Cloud | Рядом с экосистемой VK | Похож на Яндекс по сложности |
| Остаться на Supabase | Ничего не переносить | Зарубежный хостинг и риски выше |

Код не зависит от провайдера: тот же `docker compose` запускается на любом Ubuntu-сервере.

## 2. Telegram: настройка бота

Бот уже создан: **@UniversalShareBot**.

1. **Сначала безопасность.** Токен был отправлен в чат, поэтому сделайте в BotFather → бот → **Revoke** и скопируйте новый токен. Храните его только в `.env` на сервере, никогда в репозитории.
2. **Главный Mini App.** BotFather → бот → **Mini Apps** (или *Bot Settings → Configure Mini App*) → **Enable Mini App** → URL `https://ваш-домен`.
   - После этого заработают ссылки `https://t.me/UniversalShareBot?startapp=…`.
   - Через них открываются общие профили и ссылки привязки.
3. **Домен для входа на сайте.** BotFather → *Bot Settings → Domain* → `ваш-домен`. Это нужно для кнопки «Войти через Telegram» в браузере.
4. **Inline-режим** (рекомендуется): `/setinline` → любой плейсхолдер, например «Поиск игроков». Он улучшает «Поделиться анкетой» через `shareMessage`.
5. **Не настраивайте вручную:** команды, описание, кнопку меню и webhook сервер выставляет сам при каждом запуске.

## 3. ВКонтакте: Mini App (и находимость в поиске)

1. Откройте [dev.vk.com](https://dev.vk.com) → **Мои приложения** → **Создать** → тип **Mini App**.
2. В **Настройках** приложения:
   - **URL мобильной версии / версии для vk.com:** `https://ваш-домен`;
   - скопируйте **ID приложения** → `VK_APP_ID`;
   - скопируйте **Защищённый ключ** → `VK_APP_SECRET`.
3. Заполните **название, описание, ключевые слова и обложку**, затем отправьте на **модерацию в каталог**. После публикации приложение ищется внутри VK и индексируется поисковиками как страница `vk.com/app<ID>`.
4. **Уведомления (по желанию):**
   - создайте сообщество UniShare и включите в нём **Сообщения**;
   - **Управление → Работа с API → Ключи доступа**: создайте ключ с правом «сообщения» → `VK_GROUP_TOKEN`; ID сообщества → `VK_GROUP_ID`;
   - **Callback API:** адрес `https://ваш-домен/vk/callback`. Строку подтверждения положите в `VK_CALLBACK_CONFIRMATION`, а секретный ключ в `VK_CALLBACK_SECRET`. Включите события **Разрешение на получение / Запрет на получение** сообщений.

## 4. Сервер в Yandex Cloud

1. Зайдите в [console.yandex.cloud](https://console.yandex.cloud) → **Compute Cloud** → **Создать ВМ**.
2. Параметры ВМ:
   - **ОС:** Ubuntu 24.04 LTS;
   - **ресурсы:** 2 vCPU, 4 ГБ RAM, SSD 30 ГБ (для старта хватит и 2 ГБ RAM);
   - **сеть:** **публичный статический IP**; в группе безопасности откройте входящие порты **22, 80, 443**;
   - **доступ:** добавьте свой SSH-ключ.
3. **Домен:** купите его у любого регистратора (REG.RU, Яндекс 360 и т.д.) и создайте **A-запись** на IP машины.
   - Без домена для теста подойдёт `IP-с-дефисами.sslip.io`, например `51-250-1-2.sslip.io`.
4. Подключитесь (`ssh ubuntu@IP`) и запустите установщик:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/EgorChulanov/UniShare/main/cloud/deploy/setup-vps.sh)"
```

Скрипт:
- спросит домен, токен бота, VK ID и ключ;
- сгенерирует пароли и запишет `/opt/unishare/cloud/.env`;
- поставит Docker и поднимет PostgreSQL, приложение и Caddy (автоматический HTTPS);
- настроит ночные бэкапы базы.

> Скрипт берёт код из ветки `main`. Пока pull request не влит, используйте ветку с изменениями:
>
> ```bash
> sudo BRANCH=claude/cool-mendel-n5ufub bash -c "$(curl -fsSL https://raw.githubusercontent.com/EgorChulanov/UniShare/claude/cool-mendel-n5ufub/cloud/deploy/setup-vps.sh)"
> ```

**Вариант без SSH (cloud-init).** При создании ВМ откройте **Метаданные → User data** и вставьте содержимое [`cloud/deploy/cloud-init.yaml`](../cloud/deploy/cloud-init.yaml), заполнив в нём домен и токены. UniShare установится сам при первом запуске машины. Ход установки: `sudo tail -f /var/log/unishare-setup.log`.

5. **Проверка:**
   - откройте `https://ваш-домен`, там появится страница входа;
   - откройте бота, нажмите **Start** и кнопку меню **UniShare**.

**Обновление:** повторите ту же команду, или настройте автодеплой из GitHub Actions (секреты `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`, см. `.github/workflows/cloud.yml`).

### Если сервер не видит api.telegram.org

Из некоторых российских дата-центров, в том числе Yandex Cloud, исходящие запросы к `api.telegram.org` не проходят. Проверить это можно по `https://домен/health`: там `telegram.configured: false` и ошибка сети.

Сервер решает это сам. При старте он проверяет адреса `api.telegram.org` из DNS. Если они не отвечают, он перебирает запасные адреса Telegram, например `149.154.167.220`, и закрепляет первый рабочий. Сертификат `api.telegram.org` при этом по-прежнему проверяется. Выбранный путь виден в `/health` в поле `telegram.route`. Адрес можно задать вручную через `TELEGRAM_API_IP`, а список запасных адресов через `TELEGRAM_API_FALLBACK_IPS`.

Если не отвечает ни один адрес, UniShare продолжит работать: Mini App открывается, а бот отвечает на команды прямо в ответе webhook. Не будут работать только уведомления, где бот пишет первым.

В этом случае разверните бесплатный ретранслятор на Cloudflare по инструкции [`cloud/deploy/telegram-relay/README.md`](../cloud/deploy/telegram-relay/README.md) и пропишите `TELEGRAM_API_ROOT` в `.env`.

### Когда пользователей станет больше
- **База:** Yandex **Managed Service for PostgreSQL**. Укажите `DATABASE_URL=postgres://…:6432/unishare` и `DATABASE_SSL=true`, а сервис `postgres` из compose можно убрать.
- **Файлы:** **Object Storage**. Укажите `STORAGE_DRIVER=s3`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_URL`.
- **Цены** смотрите в [калькуляторе и тарифах Managed PostgreSQL](https://yandex.cloud/ru/docs/managed-postgresql/pricing). Они зависят от vCPU, RAM, диска и бэкапов.

## 5. Как это работает для пользователя

- **Вход.** Из Telegram пользователь входит автоматически, из VK тоже. На сайте он нажимает «Войти через Telegram».
- **Один аккаунт.** В **Профиль → Привязанные аккаунты** можно привязать Telegram и VK к одной анкете (ссылка действует 15 минут). Мэтчи и переписка общие на всех платформах.
- **Чаты.** Переписка хранится в UniShare (фото, прочтение, «печатает…», жалобы, блокировки, отзывы).
- **Уведомления.** Бот присылает уведомления о мэтчах и сообщениях с кнопкой, которая открывает нужный чат.
- **Связь напрямую.** Если собеседник включил «Показывать мои контакты», в чате появляется кнопка **«Написать в Telegram»** (или «Открыть ВКонтакте»), как в «Дайвинчике».
- **AirShare.** Два человека открывают AirShare рядом (кнопка-антенна на Главной). Приложение сравнивает примерную геопозицию (Telegram LocationManager, VK или браузер) или общую сеть Wi‑Fi и показывает анкеты друг друга. Позиция хранится в памяти меньше минуты.
- **Поиск.** Кнопка с лупой справа от таб-бара: игроки, игры и платформы. У каждой игры есть страница с описанием и списком игроков.
- **iPhone и Android без магазинов.** Сайт ставится на главный экран как приложение (PWA).

## 6. Данные из Supabase

Старые аккаунты входили по email. В новой системе вход идёт через Telegram или VK, поэтому автоматически сопоставить людей нельзя.

Если реальные пользователи уже есть:
- профили можно перенести SQL-выгрузкой;
- затем разослать им ссылку привязки.

Если пользователей пока нет (приложение не прошло App Store), начните с чистой базы.

## 7. Чек-лист запуска

- [ ] Токен бота перевыпущен (Revoke) и записан только в `.env`
- [ ] VM создана, A-запись домена указывает на её IP
- [ ] `setup-vps.sh` отработал, `https://домен/health` возвращает `{"ok":true}`
- [ ] В BotFather включён Mini App с URL домена и указан Domain
- [ ] VK Mini App создан, URL и ключ указаны, приложение отправлено на модерацию
- [ ] (По желанию) `RAWG_API_KEY` для рейтингов и описаний RAWG. Обложки работают и без него: сервер берёт их из Steam и Wikipedia. Ключ можно передать без входа на сервер: метаданные ВМ в Yandex Cloud, атрибут `unishare-env`, строка `RAWG_API_KEY=...` (сервер читает его при старте).
- [ ] (По желанию) сообщество VK для уведомлений
